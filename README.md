- Connects to 5 relays to fetch NOSTR events

- Ccmpares two users side-by-side
- Showcases thread interactions visually


# [Toronto Skate + Group Chat](https://sunmoonron.github.io/skate/)
- Leverage City of Toronto Open Database to view drop-in skate times for easy navigation
- Live toronto.ca service alerts — sessions at closed rinks are flagged as likely cancelled
- Extra venues beyond the city feed: Moss Park Arena (scraped, marked unverified) and Canlan York public skate (paid, $ shown) — paid venues hidden behind a 💰 toggle
- Week-calendar planner with saved-session highlights, closest-rink locator (location share / address / postal code), and "My rinks" personalization
- Toronto-timezone-correct times on any device: "Starts in Xm", "On now · Xm left", ended sessions auto-hide
- Message public group chat or create private ones
- DM features with complete ChaCha20-Poly1305 encryption end-to-end protection
- Powered by NOSTR relays
